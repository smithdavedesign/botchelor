# UX audit, 2026-10-31: phone and desktop

David's ask (2026-10-31): "do a full audit of the ux in mobile and desktop make sure wr use best in class for users.
Make sure its not crowded we group things if its too complicated make a model everything that makes sense."

This document is written for David and for whoever picks up the follow-ups. It lists every finding, what shipped and
what's left.

## How it was run

- **The captures:** `npm run e2e:visual` against a local build: every page state at phone size (390×844) and desktop
  size (1280×800), in light and dark, as a visitor, an owner and an admin. Some steps were walked: the create wizard,
  the edit wizard and the swipe deck.
- **The review:** five areas, one reviewer each. Each finding names the page, what's wrong, the fix and the files.
  - A: a first visit.
  - B: making a character.
  - C: the dating loop (swipes, matches, threads, couples).
  - D: watching, social and accounts.
  - E: After Dark and the admin pages.
- **Priorities:**
  - P1: it blocks or misleads.
  - P2: it's crowded or confusing.
  - P3: polish.
- **Checks:**
  - Every fix PR passed `tsc`, the full vitest suite (four shards, one worker), `npm run e2e`, and a visual re-run of
    the pages it touched.
  - Each was merged on green and checked live on both DigitalOcean apps.

## The short version

The show works on a phone. The problems were weight and noise, not breakage.

**What changed:**
- **One filled button per screen.** An unstyled button was a filled gradient pill, so pages had three or four
  "primary" actions. Side actions are outlined now.
- **Cards and rows open with a tap anywhere.** Before, only the name was a link: about a 22px target on a card that
  lifted on hover as if all of it were one.
- **Long pages are shorter, with the rest grouped:**
  - folds for secondary sections;
  - modals for forms that were in the page (thread actions, Unmatch, matchmaking, league join and invite,
    notification settings);
  - two-up tiles for character lists on a phone;
  - a grouped footer;
  - home's reviews cut to three quotes, with all of them on their own page.
- **The create wizard:**
  - what the swipe deck needs comes first;
  - Next says what's missing;
  - the bar sticks to the bottom of a phone.
- **Bugs found on the way:**
  - The watch room opened on Chat while a prediction was due.
  - The admin settings wiped unsaved typed edits when any toggle saved.
  - The theater's phone bar overflowed.
  - Every date was shown in UTC.
  - The edit page made a 401 request for every anonymous owner.
  - So did the roleplay picker, each time a signed-out owner opened it.

**What's left:** the bigger reworks are listed under *Not done yet*. Most of them are a page's structure, not a
style: the couple page's plan flow, the Look step, the Constellation's phone layout and After Dark's theater. The After
Dark items are botchelor-4a's code.
